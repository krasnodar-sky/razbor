- Уточнения одной фразой в №3/6/10/13/15/16/17/18/20/21/24/27: второй инстанс приложения перехватывает команды; «уже есть / запрещено» проверять перед предложением; свой субагент и авто-метка — тоже пересказ; вердикт «мертво» с чужого egress-IP; три формы лживых тестов и упавший тест с говорящим именем; три проверки активации; дубль факта сводить сейчас; края распределения и счётчики ложных плюсов/минусов; «оригинал» по имени — промерить; свой счётчик расхода ≠ счёт провайдера, квота файлов; любой «мёртв» от одной пробы — гипотеза; замена по якорю совпала не там. **№8 переписан императивно:** grep памяти первой командой; стоп собственного гейта — протокол, не обход.
- Блок «⚡ Перед мутирующей операцией»: +7 вопросов (владелец файлов при записи от root; бэкап именно этой выкатки; читатель нового поля; сухой прогон патча по якорю; упавший тест с говорящим именем; общее git-дерево; результат только в рабочей папке).
- **packs/audit.md:** предохранитель получает вердикт по артефакту (кейсы с датой прогона, тест с обходного пути), прогон кейсов после каждой выкатки, задевшей барьер; «маркер применения» конвейера в записи журнала — без него аудит и эвал не отличают мёртвое правило от применённого молча.
- Отложены (один повтор за месяц): побочная запись роняет основной результат; обновление платформы молча меняет семантику правил; форма отчёта под уровень ошибки.
- Локально у автора (вне плагина, для истории): гейт отправки — четыре класса ложных стопов августа сняты, 11 тест-кейсов рядом с хуком; стоп-хук журнала — один блок на сессию вместо каждого Stop; крон-напоминалка о пересборке получила сторож по дате последнего коммита плагина («напоминание ушло» ≠ «сделано»).
